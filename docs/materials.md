# 教材の追加と変更

## 出題内容と学年を登録する

| 教材 | 登録先と変更内容 |
| --- | --- |
| 計算・図形・データなどの追加教材 | [追加教材の定義](../src/config/supplemental-patterns.ts)に表示名・説明・学年・分野・難易度を登録し、[問題生成パターン](../src/lib/generators/patterns/)に出題処理を追加する。 |
| 学校算数の英語文章題 | [英語文章題のテンプレート](../src/lib/generators/templates/en-word-story.ts)で単元と対象学年を指定する。同じ素材が、単元別プリントと学年別の総合演習の両方に使われる。 |
| 中学受験の文章題 | [受験教材の定義](../src/config/entrance-exam-patterns.ts)に、学年・単元・日英の名前と説明を登録する。公開動画の題型から作った教材は [Studio の教材定義](../src/config/studio-topics.ts)と[対応するジェネレーター](../src/lib/generators/studio/)で管理する。 |

文章題が複数の単元にまたがる場合は `topics` にすべて指定します。例えば「水そうの深さと流量」は「仕事と流量」と「表・グラフ・平均」に該当します。教材一覧では日英ペアを1行にまとめ、件数表では該当する各単元に数えます。[教材一覧の集計](../src/config/worksheet-catalog.ts)

「学習の道すじ」に載せる場合は、前提となる技能を確認し、学校算数または中学受験の該当する段階に追加します。[学年別の学習順](../src/config/learning-paths.ts)

## 問題用紙と解答用紙を確認する

- **出題条件**。問題文の条件から解き直して正答を確かめます。例えば植木算なら、道の両端・片端・輪で木の本数と間の数の関係が変わります。乱数の上限と下限でも解けることを確認します。[受験算数の生成テスト](../src/lib/generators/entrance-exam.test.ts)
- **図と解説**。図には考えるための長さ・目盛り・単位を残し、求める値を伏せます。日本語版・英語版それぞれで、問題用紙にはヒントを出しすぎず、解答用紙で計算と解き方を追えることを確認します。
- **行数**。受験教材の `printRows` には、日本語版・英語版それぞれについて、1列・2列・3列の順に**行数**を指定します。2列で6行なら12問です。式欄付きの問題と解説付きの解答の両方が収まる値を選びます。[印刷と教材一覧の検証](print-validation.md)

## 解説動画を関連付ける

公開動画の YouTube ID、タイトル、対応する教材IDを登録します。日英ペアはどちらかの教材IDで両方に表示でき、必要に応じて開始学年を指定できます。プレーヤーは利用者が「解説動画を見る（日本語）」を押すと読み込まれます。[動画の登録先](../src/config/lesson-videos.ts)

子ども向けサイトとして動画を公開する際のサイト指定は、所有者が Google Search Console で行います。[Google の子ども向けサイト設定](https://support.google.com/policies/answer/9664901?hl=ja)
