# まいにち算数

幼児の数字なぞり書き、小学1〜6年生の計算・文章題、4〜6年生向けの中学受験算数のA4プリントをブラウザで作成できます。

[プリントを作る](https://knishioka.github.io/math-worksheet/) · [教材一覧から探す](https://knishioka.github.io/math-worksheet/#catalog)

## 教材を選ぶ

- **学年に合わせて進める**。「学習の道すじ」から教材を選ぶと問題が表示されます。練習後は「練習した」を記録して次の教材へ進めます。記録は使ったブラウザに保存されます。
- **全学年から探す**。「教材一覧」でキーワード・学年・分野・言語を絞り込み、「例題を見る」で内容を確かめます。例えば「水そう」で検索すると、6年生の「水そうの深さと流量」を日本語または英語で開けます。
- **文章題を単元から探す**。「文章題から探す」では、学校算数・中学受験・Singapore Math の教材を単元ごとに比較できます。「単元ごとの日英の教材数」の数字を押すと、該当する教材が表示されます。

教材一覧の絞り込み条件やプリントの設定は、URLで共有できます。作成済みの問題をそのまま渡したいときは、プリントをPDFに保存してください。

## 問題用紙と解答を印刷する

1. 教材を選び、プレビューを見ながら問題数・列数（1〜3列）・並び方を調整します。対応する文章題では「式を書く欄」を追加できます。「解説動画を見る（日本語）」がある教材では、その場で解き方を確認できます。
2. 「解答表示」をオフにし、「印刷（複数ページにも対応）」から1枚印刷します。ブラウザの印刷画面で用紙を **A4・倍率100%・ヘッダーとフッターなし** に設定します。同じ画面でPDFにも保存できます。
3. 同じ問題の解答用紙を作るには、教材を開いたまま「解答表示」をオンにし、もう一度1枚印刷します。新しい問題に替えるには「同じ教材で問題を作り直す」を押します。

**クラス全員に同じプリントを配るとき**は、アプリの「印刷枚数」を1枚にして、ブラウザの印刷画面で部数を増やします。アプリの「印刷枚数」を増やすと、1枚目にはプレビューの問題を使い、2枚目以降には別の問題を生成します。

## ローカルで起動する

React・TypeScript・Vite で開発しています。Node.js 24以上と npm を用意し、リポジトリのルートで実行してください。

```bash
npm ci
BROWSER=none npm run dev
```

開発用の既定URLは `http://localhost:5174/` です。`BROWSER=none` はブラウザの自動起動を抑える環境変数です。本番用ファイルは `npm run build` で `dist/` に生成します。
