# まいにち算数

> 小学校算数のカリキュラムに沿った計算プリントを、ブラウザだけで生成・印刷できるReactアプリです。

## ライブデモ

- URL: https://knishioka.github.io/math-worksheet/
- MathML対応ブラウザ（Safari、Firefox、Chromium系の最新版）で最も綺麗に表示できます。
- ブラウザ側で完結するため、個人情報や学習履歴はサーバーに送信されません。

## このアプリでできること

### 学年と学習目的に合わせた問題生成
- 学年別の教材192種類を用意。−1〜−9、九九の各段、分数の個別練習、図形・表・棒グラフまで学べます。
- 学年ごとの「学習の道すじ」に目的と振り返りを用意。基礎から活用へ順に進めます。
- 分数・小数・帯分数・百分率など、中高学年向けの内容もMathMLで美しく出力します。
- お金・時間・単位変換・温度・距離・料理など、生活科目と結び付けた応用問題を収録しています。
- 国際学校向けに、英語の文章題や英単位での換算問題も生成できます。

### 印刷しやすいワークフロー
- 設定は「学年 → パターン → レイアウト」の順にガイドされ、選択肢は学習範囲外を自動で除外します。
- 推奨問題数・最大問題数を自動で提案し、A4用紙に収まらない場合は警告を表示します。
- プレビュー画面から複数ページ分の問題をまとめて生成・印刷でき、解答欄の有無も切り替え可能です。
- 印刷レイアウトは1〜3列に対応し、列数に応じて余白と行間を最適化します。

### 安心して使える設計
- 設定はURLに反映され、ブックマークや共有から再開できます。「練習した」教材の記録はブラウザ内に保存されます。
- 生成ロジックはTypeScriptで型安全に管理し、単体テストと検証スクリプトで回帰を防ぎます。
- Node.jsのローカル環境だけで開発・ビルドでき、学校やご家庭でも簡単に導入できます。

## 技術スタック

- **フレームワーク**: React 19 + TypeScript 5.9 + Vite 7
- **状態管理**: Zustand（ローカルストレージ永続化付き）
- **スタイル**: Tailwind CSS + カスタム印刷スタイル
- **印刷**: React-to-printによる複数ページ印刷、pdfmake（オプション設定で有効化）
- **テスト**: Vitest + Testing Library、ESLint、TypeScript typecheck

## セットアップ

### 必要な環境
- Node.js 24以上（LTS推奨）
- npm 9以上

### ローカル開発の流れ
```bash
# リポジトリの取得
git clone https://github.com/knishioka/math-worksheet.git
cd math-worksheet

# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev
# ブラウザで http://localhost:5173/ を開きます
```

## 使い方

1. 学年を選び、「学習の道すじ」から今の段階に合う教材を選びます。
2. 「問題を変更」から、カテゴリ・難易度・言語・キーワードでも探せます。
   候補はカテゴリごとに表示し、「学習の道すじ順」「やさしい順」を切り替えられます。道すじの教材はカードから選び、前後の教材へも移動できます。
3. レイアウト（1〜3列）と問題数を調整します。教材変更時は推奨値を適用し、列数変更時は選んだ問題数を上限内で維持します。
4. 「解答表示」をオンにすると答え付きプリントを確認できます。
5. 「印刷（複数ページにも対応）」ボタンから必要枚数を入力し、ブラウザの印刷画面で出力します。
6. 解いた後は振り返りの問いを使い、「練習した」を記録。次の教材や復習へ進みます。

画面のプレビューは「用紙全体」「原寸で見る」を切り替えられます。印刷はA4・倍率100%・ヘッダーとフッターなしを指定してください。

キーワード検索は全角・半角とひらがな・カタカナの違いを吸収し、空白で区切った複数のキーワードで絞り込めます。検索を開くと入力欄へ移動し、Escapeキーで閉じられます。

列数・解答表示・式を書く欄の変更では、生成済みの問題を維持します。問題数を減らすと末尾を削り、増やすと不足分だけを追加します。新しい問題に切り替えるには「同じ教材で問題を作り直す」を押してください。

問題の並びは「たて順（列ごとに上から下）」「よこ順（行ごとに左から右）」を選べます。たて順では列ごとの問題数を均等に配分し、並び方は共有URLと印刷にも反映します。

印刷・PDF保存の直前に、全ページの縦横の寸法と列内のはみ出しを確認します。はみ出しがある場合は出力を中止し、問題数や列数の調整方法を表示します。フォントの読み込み後、印刷用iframeでも検査します。

## 品質チェック

開発者は以下のコマンドで品質ゲートを通過させてからコミットしてください。

```bash
npm run lint         # ESLint
npm test -- --run    # Vitest（ウォッチ無効）
npm run typecheck    # TypeScript型チェック
npm run build        # 本番ビルド確認
```

必要に応じて `verify-*.mjs` スクリプトで問題生成ロジックの追加検証を実施できます。

CIはテスト・lint・型チェック付きビルド・印刷/PDF検査を同じジョブで実行し、依存関係の導入とビルドの重複を避けます。印刷/PDF検査はアプリ変更を含むPRで実行し、文書だけのPRでは重い処理を省略します。PR更新時は古い実行をキャンセルし、Chromiumは検証に使うheadless shellだけを導入します。mainへのpushでは品質チェック後にPagesへデプロイします。
